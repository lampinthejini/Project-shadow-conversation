[재방문]

[저장한 그림자 다시 열기]

   -> 상대 선택·현상 건너뜀 -> 공간 전환 -> SCR-05 이어서 대화 (첫 대사 고정 문구)
   -> 또는 SCR-07에서 지난 장면 선택 -> "이 장면에 다시 빛을 비춘다" -> 새 갈래 SCR-05 (그 장면에서 사용자가 새로 답하는 것부터 시작)

[위기 분기 : 사용자가 입력하는 모든 화면(SCR-03, SCR-04, SCR-05, SCR-06 안부 답변)]
 위기 키워드 감지 ──> 판정기 대기 없이 즉시 위기 안내 카드(CMP-04) + 지배인 고정 문구, 그림자·지배인 출력 차단, L2 사전 적중은 L2(세션 보류)·L3 사전 적중은 L3(보류 + 자정까지 잠금)
 키워드 없음 ──> LLM 판정: L0 계속 / L1 자각 대사, 세션 후 지배인 안부 / L2·L3 연기 중단 + 위기 안내 카드 + 지배인 고정 문구, 세션 보류
 판정 실패·시간 초과 ──> 응답 폐기, 재입력 요청 / 같은 턴 2회 실패 ──> 세션 보류(종료 사유: 판정 실패)

## 2. SCR-01 튜토리얼(다른 손님 엿보기)

### 2.1 목적과 우선순위

고정 스크립트로 다른 손님의 대화를 보여주고, 지배인이 사용자를 발견하는 장면으로 세계관(암실·지배인·그림자·빛)을 알린다. LLM 호출 없음 [제안].

- 관련 F-xx: F-01. 우선순위 P0. 개발 단계 1단계.
- 수용 기준: 3분 이내, 건너뛰기 가능.

## 3. SCR-02 가입·로그인

### 3.1 목적과 우선순위

튜토리얼을 본 뒤 가입하거나, 재방문 사용자가 로그인한다. 가입·로그인 전에는 로비(지배인 대화) 이후로 들어갈 수 없다. 비회원 대화는 없다 [확정, PRD v0.9 F-02].

- 관련 F-xx: F-02, F-09(저장), F-11(탈퇴 일괄 삭제). 우선순위 P0. 개발 단계 1단계(테스트 계정 로그인).
- 수용 기준: 비회원의 로비 이후 진입 0건, 가입은 3단계 이하(가입은 외부 공개 시점부터).
- **테스트 단계(외부 공개 전: 로컬 시연·지인 체험)** [확정, PRD v0.9 F-02]: [가입] 탭과 가입 단계, 성인 확인을 구현하지 않는다. 운영자가 미리 만든 테스트 계정으로 [로그인]만 한다. 아래 가입 관련 요소는 외부 공개 때 D-11과 함께 확정한다.
- 민감정보 동의와 성인 확인은 이 화면이 아니라 SCR-04 앞단(5.2)에서 받는다.

## 4. SCR-03 암실 로비(지배인 대화)

### 4.1 목적과 우선순위

지배인이 사용자를 맞이하고 "어떤 대화를 하고 싶은가"를 묻는다. 상황 선택(F-03)과 저장한 그림자 열기의 진입점이다.

- 관련 F-xx: F-03, F-04 진입, F-09(이어하기 진입), F-15(P1, 반복 고통 신호 시 권유 1회), F-14(P1, 암실 밝기).
- 우선순위 P0. 개발 단계 1단계.
- 수용 기준(F-03): 선택지는 지배인 대사 안에 제시, 자유 대화는 상황을 직접 적을 수 있음.
- 로비의 지배인 대사는 사용자 입력 없이 나오므로 고정 문구로 한다 [확정, PRD v0.9 9절]. 인터뷰 첫 질문, 마무리 제안, 쉬어 가기 권유도 같다.
- 로비에서는 자유 입력을 받지 않고 선택지만 고른다. 자유 대화의 상황 설명은 동의를 받은 뒤 SCR-04 첫 질문에서 적는다. 민감한 내용이 동의 전에 입력되지 않게 하기 위해서다 [제안-UI].

## 5. SCR-04 그림자 현상 인터뷰

### 5.1 목적과 우선순위

지배인이 3~5개 질문으로 관계, 시간 축(지나온 관계/다가올 가능성), 호칭, 하고 싶은 말, 감정 키워드를 받아 "그림자 카드"를 만든다. 인터뷰 앞단에서 민감정보 동의와 성인 확인을 받는다 [확정, PRD v0.9 F-02].

- 관련 F-xx: F-04, F-02(동의·성인 확인), F-19(캠 없이 진행 체크박스), 6.5(음성 프리셋).
- 우선순위 P0. 개발 단계 1단계(카드 생성). 음성 프리셋·목소리 등록·표정 옵션은 4단계.
- 수용 기준(F-04): 상황과 상대를 따로 고름, 자유 설정 허용, 실명·연락처는 마스킹.

### 5.2 구성 요소

```

|   [입력창 / 선택지]                         [다음]   |
|                                                      |
| [x] 캠 없이 진행   (기본 체크)                       |
| 목소리 프리셋: 성별 / 나이대 / 톤        (4단계)     |
+------------------------------------------------------+
```

## 6. SCR-05 대화 화면(배경 + 그림자 + 채팅)

### 6.1 목적과 우선순위

고른 상황의 배경 위에서 그림자와 대화한다. 안전·판정·음성·속마음·표정 처리가 모두 모이는 핵심 화면이다.

- 관련 F-xx: F-05(공간 전환), F-06(빛과 대화 시작), F-07, F-08(마무리 제안 수신), F-10, F-13(P1), F-14(P1), F-19(P1), F-09(자동 저장), F-18(새 갈래에서 진입).
- 우선순위 P0. 개발 단계 1단계(텍스트), 4단계(음성·속마음·표정).
- 수용 기준: 연출 3초 이내(F-05), 빈 화면 없이 그림자가 먼저 말을 건넴(F-06), 캐릭터 루브릭 통과(F-07), 판정 전 출력 0건(PRD 9절 처리 우선순위, 11절 1단계 "판정기(병렬 + 출력 보류)").

| 시작 | 빛을 가져오는 연출 | 지배인이 빛을 가져오면 그림자가 먼저 첫 대사. 세션 시작(새 그림자·이어하기)의 첫 대사는 상황별 고정 문구이며 판정 대기 없이 바로 표시 [확정, PRD v0.9 F-06]. 새 갈래는 고른 장면에서 사용자가 새로 답하는 것부터 시작 | F-06, F-18 |

| 채팅 | 텍스트 입력 + 보내기 | 텍스트는 항상 가능한 보조 수단. 전송 시 판정 시작 | F-07 |
| 채팅 | 그림자 응답 표시 | "안전" 판정 이후에만 로그에 표시. 판정 전에는 버퍼(화면에 없음) | F-10, 9절 |
| 음성 | 말하기 버튼(push-to-talk) | 누르는 동안 녹음, 떼면 전송. 버튼 상태는 항상 표시 | F-07, 6.5 |
| 음성 | CMP-01 마이크 상태 표시와 끄기 | 세 상태 전환. 상세는 6.3.3과 7.1(CMP-01) | 6.5 |
| 기분 | CMP-03 기분 표시 | 내 실루엣 주변 빛 색 + 텍스트 라벨 | 6.5 |
| 기분 | "지금 기분" 선택 버튼 | 속마음 미동의 시 같은 역할. 기분 라벨 후보(9개 안)에서 선택 [가설] | 6.5 |
| 카메라 | CMP-02 카메라 상태 표시, 끄기 | 작게 표시, 읽힌 표정 표시(관찰 표현). 끄면 스트림 정지 | 6.7 |
| 카메라 | "캠 없이 진행" 체크박스 | 대화 중에도 변경 가능. 다음 턴부터 적용 | 6.7 |

| 종료 | 마무리 제안 말풍선(지배인) | 판정기 매듭 신호 시 지배인이 제안. [끝낸다] [계속한다] 선택. 거절 가능 | F-08 |
| 종료 | 사용자 종료 요청 / "이 그림자 보내기" | 어느 단계에서든 요청 가능. "보내기"는 지배인에게 청하고, 그림자가 그 맥락에 맞는 마지막 대화를 한 뒤 SCR-06 | 6.2, F-08 |
| 안전 | CMP-04 위기 안내 카드 | 위기 시 대화 영역 위에 고정 표시 | F-10 |
| 저장 | 자동 저장 표시 | 자동 저장 상태 표시(저장 기능은 2단계부터) | F-09 |

### 6.3 상태

#### 6.3.1 로딩 / 판정 대기 (그림자 응답 비노출 원칙)

| 단계 | 화면 표시 | 비고 |
| --- | --- | --- |
| 세션 첫 대사 | 빛 연출 뒤 상황별 고정 문구를 바로 표시 | LLM 생성이 아니므로 판정 대기 없음. "빈 화면 없이"(F-06)를 충족 |
| 사용자 전송 직후 | 내 대사는 로그에 즉시 표시, 입력창 잠금 | 중복 전송 방지 |
| 위기 키워드 규칙 | 즉시 실행(사용자에게 별도 표시 없음) | 걸리면 7.4 위기 흐름으로 |
| 모델 생성 중 + 판정 대기 중 | "그림자가 생각하는 중"과 같은 중립 표시만 노출(점 애니메이션 등). **생성 중인 그림자 응답의 일부(스트리밍 토큰, 부분 문장, 음성 선재생)는 화면에도 스피커에도 나가지 않는다** | 병렬/순차 방식과 무관하게 동일 [확정] |
| 판정 "안전"(L0·L1) | 버퍼의 그림자 응답을 로그에 표시하고, 음성 모드면 TTS 재생. L1이면 그림자 응답은 자각 대사로 나간다. L2·L3이면 응답을 폐기하고 6.3.5로 | 출력 승인 이후에만 TTS 합성·재생을 시작하는지, 출력 확정 뒤에 합성을 시작한다(TRD 5.2) |
| 지연 | 대기 시간이 길어져도 응답을 부분 공개하지 않는다. 장시간 표시(예: 일정 시간 초과)에 대한 문구는 [제안-UI]이며 임계값은 0단계 후 확정 | 판정 타임아웃은 3초 [가설] |
| 선명도·빛 | 판정 결과에 따라 변경되는 연출은 응답 표시와 같은 시점에 반영 | F-13, F-14 |

#### 6.3.3 마이크 세 상태 (PRD 6.5 [확정])

세 상태의 이름과 의미는 PRD 6.5 그대로이다.

| 상태 | PRD 정의 | 화면 표시 | 처리 |
| --- | --- | --- | --- |
| 말하기 | 버튼을 누르는 동안의 말은 그림자에게 건네는 **대사** | 말하기 버튼이 눌린 상태. 텍스트 라벨 "말하는 중" + 아이콘 + 레벨 표시 | 떼면 전송. STT 후 판정을 거쳐 처리 |
| 속마음 듣는 중 | 버튼을 누르지 않고 마이크가 켜진 채 한 말은 **속마음** | "듣는 중" 라벨 상시 노출(색에만 의존 금지). 속마음 동의 후에만 가능 | 화자 확인 -> STT·운율 -> 위기 판정 -> 기분 추출. 원문은 즉시 버림 |
| 마이크 끔 | 끄면 브라우저에서 녹음 자체가 멈춤 | "마이크 꺼짐" 라벨 상시 노출 | 스트림 중지. 서버 무시가 아님 |

- 상태 전환은 마이크 끄기 버튼으로 한다. 끄면 즉시 수집이 중단된다 [확정].
- 상태는 이 세 가지뿐이다. 속마음에 동의하지 않은 사용자에게는 "속마음 듣는 중"이 없다. 말하기 버튼을 누르지 않는 동안은 "마이크 끔"이고, 누르는 동안만 스트림을 열어 "말하기"가 된다(PRD 6.5 "속마음 채널은 별도 동의를 받은 사용자에게만 켜진다"). 별도의 "대기" 상태는 두지 않는다.

| 지금 상태 | 사건 | 다음 상태 |
| --- | --- | --- |
| 마이크 끔 | 말하기 버튼 누름 | 말하기(스트림 열기) |
| 말하기 | 버튼 뗌(누르기 전 상태가 마이크 끔) | 마이크 끔(스트림 닫기) |
| 말하기 | 버튼 뗌(누르기 전 상태가 속마음 듣는 중) | 속마음 듣는 중 |
| 속마음 듣는 중 | 말하기 버튼 누름 | 말하기(누르는 동안의 말은 대사로만 처리, 속마음 수집 중단) |
| 속마음 듣는 중 | 마이크 끄기 | 마이크 끔(스트림 정지) |
| 마이크 끔 | 마이크 켜기(속마음 동의자만) | 속마음 듣는 중 |
| 어느 상태든 | 설정 진입, 마무리 화면 이동, 위기 카드 표시 | 마이크 끔(스트림 정지) |

- 에코 차단: TTS 재생 중에는 속마음 수집을 일시정지하거나 에코를 제거한다. 일시정지 중에는 "재생 중, 속마음 잠시 멈춤" 안내를 띄운다 [제안-UI]. 이것은 네 번째 상태가 아니라 "속마음 듣는 중"에 붙는 안내다. 그림자 음성이 속마음으로 전사된 건수 0이 수용 기준이다.
- 마이크 권한 거부·장치 없음: 텍스트 입력만으로 진행. 지배인 알림은 [제안-UI].

#### 6.3.4 카메라 상태와 "캠 없이 진행" (PRD 6.7)

| 상태 | 표시 | 동작 |
| --- | --- | --- |
| 캠 없이 진행(체크, 기본값) | "카메라 사용 안 함" 라벨 | 카메라 권한 요청 0건. 표정 채널 꺼짐. 기분은 목소리나 "지금 기분" 버튼으로만 전달. 그림자는 표정을 언급하지 않음 |
| 켜짐(체크 해제 + 동의 + 권한 허용) | "카메라 켜짐" + 읽힌 표정(예: "미소가 보여요" 같은 관찰 표현, 단정 금지) 작게 표시 | 브라우저에서만 분석. 표정 신호와 신뢰도만 1~2초마다 서버 전송 [가설]. 영상·사진·특징값 저장 안 함 |
| 꺼짐(사용자가 끔) | "카메라 꺼짐" | 브라우저에서 스트림 정지. 체크박스 상태와 연동하는 방식은 확인 필요 |
| 얼굴 안 보임 | 아이콘 + "얼굴이 잘 보이지 않음" | 신뢰도가 낮으면 표정 채널이 조용히 쉼. 대화는 그대로 |
| 권한 거부·카메라 없음·다른 프로그램 사용 중 | 자동으로 "캠 없이 진행" 재체크 + 지배인이 안내 | 오류로 대화가 멈추지 않음 |

- 대화 중 변경은 다음 턴부터 적용되며 그림자 프롬프트의 카메라 여부도 함께 바뀐다.
- 표정·기분 라벨은 위기 판정에 쓰지 않는다 [확정]. 화면에서도 위기 안내를 표정 기반으로 띄우지 않는다.

#### 6.3.5 위기 안내

- 위기 안내는 7.4 CMP-04 규칙을 따른다. 화면 동작 요약:
  - 위기 키워드: 판정기를 기다리지 않고 CMP-04와 지배인 고정 문구를 즉시 표시, 그림자 출력 차단. L2 사전 적중은 L2, L3 사전 적중은 L3로 처리해 연기 중단, 세션 보류, SCR-06 보류 변형으로 간다. L2 사전 적중 뒤에도 판정기가 L3로 올릴 수 있다(PRD v0.9 7절).
  - L1: 그림자가 자기 존재의 한계를 말하는 자각 대사로 계속(세계관 유지). 세션 후 지배인이 짧게 안부를 묻는다(SCR-06에서).
  - L2: 그림자 연기 즉시 중단, 지배인이 몰입을 풀고 고정 문구로 말을 건넴(LLM 생성 아님, PRD v0.9 7절), 고정 카드 노출, 세션 보류.
  - 위기 카드는 사용자가 있는 화면 위에 바로 띄운다. 대화 중 설정(SCR-08)에 가 있어도 그 화면 위에 띄운다. 마이크·카메라 스트림은 멈춘다.
  - L3: L2 + 112·119 안내 추가, 당일 그림자 대화 재개 불가.
  - 속마음 채널의 위기 신호도 대사와 똑같이 처리한다. 음성 모드에서는 카드와 함께 미리 녹음한 고정 음성으로 안내한다.
  - 화자 확인에 실패한 발화는 서버에서 즉시 버려지므로 위기 신호를 볼 수 없다. 이 한계를 도움말(SCR-08)에 밝힐지는 D-09.

### 6.4 전환

| 구분 | 내용 |
| --- | --- |
| 들어오는 곳 | SCR-04(새 그림자), SCR-07(이어하기·새 갈래), SCR-08(대화 중 설정에서 복귀) |
| 나가는 곳 | SCR-06(마무리·보류·위기 종료), SCR-08(설정) |
| 설정 진입 | 마이크·카메라 스트림을 멈춘다. 처리 중이던 그림자·지배인 응답은 폐기하고, 입력창에 쓰던 글은 남긴다. 복귀 시 마이크는 "마이크 끔"으로 시작하고(사용자가 다시 켬), 카메라도 자동으로 다시 켜지 않고 사용자가 켠다(TRD D-T20). 폐기한 턴은 복귀 후 지배인이 고정 대사로 다시 말해 달라고 청한다 |
| 조건 | 강제 종료는 L2 이상에서만. 세션 턴 상한은 없다(PRD v0.9) |
| 이탈 | 창 닫기·새로고침 시 마지막 턴까지 저장(F-09) |

## 8. SCR-06 마무리 화면

### 8.1 목적과 우선순위

대화를 매듭짓고 저장 여부를 안내한다. 정상 종료, 사용자 종료, 위기, 판정 실패 보류가 이 화면(또는 변형)으로 모인다.

- 우선순위 P0. 개발 단계 1단계(종료), 2단계(저장).
- 수용 기준: 강제 종료 없음(L2 이상 제외), 창을 닫아도 마지막 턴까지 보존(회원).

## 9. SCR-07 갈래 보기

### 9.1 목적과 우선순위

저장한 그림자와 갈래 목록을 보고, 지난 대화의 한 지점을 골라 "이 장면에 다시 빛을 비춘다"로 새 갈래를 시작한다. 원본은 보존된다.

- 관련 F-xx: F-18, F-12(P1, 보관소 최소 화면), F-13(갈래별 선명도), F-11(삭제).
- 우선순위 P0(F-18), P1(F-12). 개발 단계 2단계.
- 수용 기준(F-18, PRD v0.9 원문): 새 갈래를 만들거나 진행해도 원본 갈래는 수정·삭제되지 않음(사용자가 직접 지우는 경우는 9절 갈래 저장 규칙을 따름), 두 갈래를 각각 다시 열 수 있고 서로 영향 없음.

### 9.3 상태

| 상태 | 정의 |
| --- | --- |
| 로딩 | 목록 로딩 중 골격(skeleton) 표시. 대화 로그 열람은 선택 시 지연 로딩. 이 화면은 그림자 응답 생성이 없으므로 판정 대기 해당 없음. 새 갈래 생성 중에는 "빛을 비추는 중" 표시, 완료 전까지 중복 생성 방지 |

| 마이크 | 마이크 사용 안 함. 해당 없음 |
| 카메라 | 사용 안 함. 해당 없음 |

| 갈래의 기분 | 기분 라벨은 저장되지 않으므로 이 화면에 표시되지 않음 |

## 10. SCR-08 설정(기록 삭제·도움말)

### 10.1 목적과 우선순위

기록 삭제, 속마음·표정 채널 제어, 도움말을 제공한다. 사용자가 원하는 종료·저장·삭제가 즉시 반영된다는 신뢰의 근거 화면이다.

- 관련 F-xx: F-11, F-19(캠 없이 진행), F-15 일부(안내), 6.5(속마음·목소리 특징값), 8절(보존 규칙).
- 우선순위 P0. 처음 선택은 해당 화면에서 하고(예: "캠 없이 진행"은 SCR-04), 바꾸는 것은 이 화면의 설정 목록에서 한다.
- 단계별 항목(PRD 11절에 맞춘 배치):

| 단계 | 이 화면에 있는 항목 |
| --- | --- |
| 1단계 | 도움말(이 경험의 성격, 위기 연락처 열람, 튜토리얼 다시 보기, 라이선스 고지), 로그아웃. "캠 없이 진행"은 체크 고정으로 표시만(표정 채널이 아직 없음) |
| 2단계 | 자동 파기 선택 설정 |
| 3단계 | 기록 삭제(그림자별·갈래별·전체), 탈퇴, 데이터 처리 안내 |
| 4단계 | 마이크·속마음 켜기/끄기, 목소리 특징값 삭제, "캠 없이 진행" 해제·표정 채널 켜기/끄기 |
- 수용 기준(F-11): 삭제 즉시 화면에서 사라지고 복구 불가, 백업은 30일 내 파기.

## 12. 공통 예외 처리 표

모든 화면에 공통이며, 화면별 상태에서 별도로 적지 않은 경우 이 표를 따른다. 모든 오류 표시와 로그에 대화 내용·속마음·표정·음성을 넣지 않는다(ID·시각만).

| E-01 | 위기 키워드 감지 | CMP-04와 지배인 고정 문구 즉시 표시, 그림자·지배인 출력 차단, 연기 중단, 세션 보류 후 SCR-06 보류 변형 | 판정기 대기 없음. 사전 등급(L2·L3)으로 처리. 위기 이벤트는 등급·시각만 기록 | F-10, PRD 7·9절 |
| E-02 | 판정 실패·시간 초과 | 그림자 응답 폐기, 지배인 고정 대사로 재입력 요청 | 폐기 응답은 UI·로그에 남기지 않음 | 9절 |

## 13. 접근성 최소 기준

PRD 8절의 "어두운 UI 가독성: 본문 텍스트 대비 4.5:1 이상, 글자 크기 조절"을 기준으로, 이 문서에서 정하는 최소 기준은 다음과 같다. 구현 가능성은 프론트엔드 담당자 확인이 필요하다.

| 항목 | 기준 |
| --- | --- |
| 대비 | 본문 텍스트 대비 4.5:1 이상 [PRD 8절]. 암실 연출보다 가독성을 우선한다. 위기 안내 카드는 연출을 걷고 최대한의 가독성을 확보한다(CLAUDE.md 4절 취지) |
| 글자 크기 | 사용자가 조절 가능. 확대 시 레이아웃이 깨지지 않을 것(반응형은 시각 설계 문서에서 구체화) |
| 키보드 | 모든 버튼·선택지·입력창·다이얼로그를 키보드로 조작 가능. 초점 순서가 논리적이고 초점 표시가 보일 것. 말하기(push-to-talk)는 키 누름/뗌 또는 토글 대체 조작 필요(방식은 확인 필요). 위기 카드가 뜨면 초점이 카드로 이동하고 Esc 닫기는 L2 이상에서 세션 재개를 의미하지 않음 |
| 텍스트 대체 | 모든 TTS 출력에 자막(PRD 6.5). 위기 음성 안내에도 텍스트 카드 병행. 그림자 형상·배경·빛 연출 변화는 텍스트 설명(대체 텍스트 또는 선명도·기분 라벨 텍스트)을 함께 제공 |
| 색에만 의존 금지 | 마이크 세 상태, 카메라 상태, 기분 표시(빛 색), 선명도, 오류·위기 상태는 아이콘·텍스트 라벨을 병기. 기분은 빛 색 + 텍스트 라벨 |
| 스크린 리더 | 상태 변화(마이크 상태, 카메라 상태, 판정 대기 중, 새 대사 도착, 위기 카드)를 적절한 live region으로 알림. 위기 카드는 즉시 알림(assertive). 일반 대사는 정중한 알림(polite) |
| 움직임 | 공간 전환·빛 연출은 시스템의 "동작 줄이기" 설정을 따르고 대체 정적 표시를 제공(요구사항에 없는 복잡한 애니메이션은 추가하지 않는다) |
| 시간 제한 | 사용자 입력에 시간 제한을 두지 않는다(그림자는 재촉하지 않고 기다림, 6.5). 재입력 요청도 시간 압박 없음 |
| 터치 대상 | 버튼 크기·간격은 시각 설계에서 정하되 모바일 터치 사용을 고려. 구체 수치는 시각 설계 문서에서 확정 |
| 오류 접근성 | 오류는 위치·텍스트로 안내하고 색만으로 표시하지 않음 |
